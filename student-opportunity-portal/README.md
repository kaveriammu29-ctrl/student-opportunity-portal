# Student Opportunity Portal

A simple React + Vite student portal to explore internships and project opportunities, apply, and track applications.

## Run locally
1. Install [Node.js](https://nodejs.org/).
2. Open this folder in VS Code.
3. Open Terminal and run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL shown in the terminal (usually http://localhost:5173).

## Features
- Demo student sign-in / registration
- Browse internship and project opportunities
- Search and filter opportunities
- Apply to opportunities
- View and withdraw applications
- Saves demo data in browser localStorage

## Note
This is a front-end academic demo. Sign-in and application data are stored only in the current browser using localStorage. It does not use a real backend, database, or production authentication.
